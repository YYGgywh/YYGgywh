# 数据库迁移脚本说明

## 迁移脚本列表

| 脚本 | 功能 | 适用场景 |
|------|------|----------|
| `migrate_comment_text.py` | 将 comment 表的 content 字段从 VARCHAR 迁移到 TEXT | SQLite 数据库 |

## 使用方法

### 1. 执行迁移

```bash
cd backend
python app/db/migrations/migrate_comment_text.py
```

### 2. 迁移流程

脚本会自动执行以下操作：
1. 检查当前字段类型
2. 创建新表（使用 TEXT 类型）
3. 复制数据到新表
4. 删除旧表
5. 重命名新表
6. 重建索引
7. 验证迁移结果

### 3. 注意事项

- ⚠️ **备份数据**：执行迁移前请备份数据库
- ⚠️ **SQLite 专用**：此脚本仅适用于 SQLite 数据库
- ⚠️ **数据保留**：迁移过程中会保留所有评论数据

## 迁移历史

### 2026-03-21
- **迁移内容**：comment.content 字段类型 VARCHAR -> TEXT
- **原因**：支持更长的评论内容（最多 1000 字符）
- **影响表**：comment
- **影响字段**：content

## 常见问题

### Q: 迁移失败怎么办？
A: 检查数据库文件是否存在，以及是否有足够的磁盘空间。

### Q: 迁移后数据丢失？
A: 迁移脚本会保留所有数据，如果数据丢失，请从备份恢复。

### Q: 如何回滚？
A: SQLite 不支持事务回滚 DDL 操作，建议迁移前备份数据库。
