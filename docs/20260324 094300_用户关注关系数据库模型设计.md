#### 字段详细说明

**1. id (主键)**
- 类型：Integer
- 约束：PRIMARY KEY, AUTOINCREMENT
- 说明：唯一标识每条关注关系
- 与现有代码保持一致（参考 PanLike、PanCollect）

**2. follower_id (关注者ID)**
- 类型：Integer
- 约束：NOT NULL, FOREIGN KEY (user.id)
- 说明：发起关注操作的用户ID
- 约束：必须是已存在的用户

**3. followed_id (被关注者ID)**
- 类型：Integer
- 约束：NOT NULL, FOREIGN KEY (user.id)
- 说明：被关注的用户ID
- 约束：必须是已存在的用户

**4. create_time (创建时间)**
- 类型：Integer (Unix时间戳)
- 约束：NOT NULL
- 说明：记录关注关系建立的时间
- 格式：秒级时间戳（如：1678886400）
- 与现有代码保持一致（参考 PanLike、PanCollect）

**5. status (关系状态，可选)**
- 类型：Integer
- 约束：NOT NULL, DEFAULT 1
- 枚举值：
  - `1` - 正常关注（默认）
  - `0` - 已取消关注
  - `2` - 拉黑（双向关系）
- 说明：支持软删除和状态管理（可选字段）
- 注意：现有代码（PanLike、PanCollect）没有此字段，直接删除记录

**6. deleted_at (删除时间，可选)**
- 类型：Integer (Unix时间戳)
- 约束：NULL
- 说明：软删除标记，NULL表示未删除
- 格式：秒级时间戳
- 注意：现有代码（PanLike、PanCollect）没有此字段，直接删除记录

## 3. 功能实现

### 3.1 关注操作实现

#### 业务逻辑

```python
# backend/app/services/follow_service.py

class FollowService:
    def toggle_follow(self, follower_id, followed_id):
        """
        关注/取消关注
        """
        # 1. 防止关注自己
        if follower_id == followed_id:
            raise ValueError("不能关注自己")
        
        # 2. 查询现有关系
        follow = self.db.query(UserFollow).filter(
            UserFollow.follower_id == follower_id,
            UserFollow.followed_id == followed_id,
            UserFollow.deleted_at.is_(None)
        ).first()
        
        current_time = int(time.time())
        
        if follow:
            # 已关注 -> 取消关注
            follow.status = 0  # 标记为已取消
            follow.updated_at = current_time
            self.db.commit()
            return {
                "is_followed": False,
                "action": "unfollow"
            }
        else:
            # 未关注 -> 关注
            new_follow = UserFollow(
                follower_id=follower_id,
                followed_id=followed_id,
                status=1,
                created_at=current_time,
                updated_at=current_time
            )
            self.db.add(new_follow)
            self.db.commit()
            return {
                "is_followed": True,
                "action": "follow"
            }
```

#### 重复关注处理机制

**方案一：数据库唯一索引（推荐）**
- 利用唯一索引 `uk_follower_followed` 防止重复插入
- 应用层捕获重复键异常
- 返回友好错误信息

**方案二：应用层检查**
- 插入前先查询是否存在有效关系
- 存在则拒绝操作
- 优点：可以提供更详细的错误提示

### 4.2 缓存策略

#### 缓存设计

```python
# 缓存键设计
CACHE_KEY_FOLLOWING = "user:following:{}"        # user:following:{user_id}
CACHE_KEY_FOLLOWERS = "user:followers:{}"        # user:followers:{user_id}
CACHE_KEY_STATUS = "user:follow:status:{}-{}"    # user:follow:status:{follower_id}-{followed_id}

# 缓存过期时间
CACHE_TTL_FOLLOWING = 3600      # 1小时
CACHE_TTL_STATUS = 300          # 5分钟
```

#### 缓存更新策略

```python
def toggle_follow_with_cache(self, follower_id, followed_id):
    """
    关注/取消关注（带缓存更新）
    """
    # 执行关注操作
    result = self.toggle_follow(follower_id, followed_id)
    
    # 清除相关缓存
    cache.delete(CACHE_KEY_FOLLOWING.format(follower_id))
    cache.delete(CACHE_KEY_FOLLOWERS.format(followed_id))
    cache.delete(CACHE_KEY_STATUS.format(follower_id, followed_id))
    
    return result

def is_following_with_cache(self, follower_id, followed_id):
    """
    检查关注状态（带缓存）
    """
    cache_key = CACHE_KEY_STATUS.format(follower_id, followed_id)
    cached = cache.get(cache_key)
    
    if cached is not None:
        return cached
    
    is_followed = self.is_following(follower_id, followed_id)
    cache.set(cache_key, is_followed, CACHE_TTL_STATUS)
    
    return is_followed
```

        """
        关注/取消关注（直接删除记录，不使用软删除）
        
        Args:
            follower_id: 关注者用户ID
            followed_id: 被关注者用户ID
        
        Returns:

        """
        # 防止关注自己

            raise ValueError("不能关注自己")
        
        # 查询现有关系
        follow = self.db.query(UserFollow).filter(
            UserFollow.follower_id == follower_id,
            UserFollow.followed_id == followed_id
        ).first()
        
        if follow:
            # 已关注 -> 取消关注（直接删除记录）
            self.db.delete(follow)
            self.db.commit()
            
            return {
                "is_followed": False
            }
        else:
            # 未关注 -> 关注
            new_follow = UserFollow(
                follower_id=follower_id,
                followed_id=followed_id
            )
            self.db.add(new_follow)
            self.db.commit()
            
            return {
