# 移动端用户中心技术文档

## 1. 项目概述

### 1.1 项目背景

随着移动设备的普及，用户越来越倾向于使用手机访问网站。为了提供更好的移动端用户体验，需要为用户中心页面设计专门的移动端界面，使其符合现代移动应用的设计标准和用户习惯。

### 1.2 设计目标

- 提供符合移动端用户习惯的界面设计
- 实现响应式布局，适配不同屏幕尺寸
- 优化移动端交互体验
- 保持功能完整性的同时提升视觉效果
- 提供流畅的动画和过渡效果

### 1.3 设计参考

设计参考了现代社交媒体应用的布局风格，采用卡片式设计和底部导航栏，提供直观的用户界面。

## 4. 核心组件设计

### 4.1 MobileUserProfileHeader 组件（新建）

**功能**：
- 头像上传和展示
- 个人信息展示（昵称、登录名）
- 数据统计（获赞、互关、关注、粉丝）
- 编辑主页功能
- 个人简介管理
- 性别年龄信息
- 所在地标签

**Props**：
```javascript
interface MobileUserProfileHeaderProps {
  userInfo: UserInfo;
  onAvatarUpload: (file: File) => Promise<void>;
  onProfileUpdate: (data: Partial<UserInfo>) => Promise<void>;
}
```

**状态管理**：
- 头像文件状态
- 编辑模式状态
- 表单输入状态

### 4.2 记录类型标签栏（复用 CardTags）

通过增强 CardTags 组件实现记录类型切换功能，无需独立创建 RecordTypeTabs 组件。

**使用方式**：
```jsx
import CardTags from '../../../Card/CardTags/CardTags';

<CardTags 
  tags={['六爻', '梅花', '八字', '奇门']}
  activeTag={currentType}
  onTagClick={(type) => setType(type)}
  interactive={true}
  maxTags={4}
/>
```

**新增 Props 说明**：
| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `activeTag` | `string` | `undefined` | 当前激活的标签值 |
| `onTagClick` | `function` | `undefined` | 标签点击回调，参数为点击的标签值 |
| `interactive` | `boolean` | `false` | 是否启用交互模式（控制容器背景透明） |
| `maxTags` | `number` | `3` | 最多显示标签数量 |

## 5. 功能模块实现

**实现要点**：

**API 调用**：
- `uploadAvatar`：上传头像

### 5.2 排盘记录管理

**实现要点**：

**API 调用**：

- `toggleCollect`：切换收藏状态

### 5.3 关注系统

**实现要点**：
- 关注列表：展示关注的用户
- 粉丝列表：展示粉丝

**API 调用**：
- `getFollowingList`：获取关注列表
- `getFollowersList`：获取粉丝列表

**实现要点**：

## 6. 响应式设计

### 6.1 断点设置

- **移动端**：< 768px
- **平板**：768px - 1024px
- **桌面**：> 1024px

### 6.2 布局策略

- **移动端**：单列布局，底部导航栏（Navigation 组件内置）
- **平板**：双列布局，侧边导航
- **桌面**：三列布局，完整功能

### 6.3 适配方案

- 使用 CSS Media Queries 实现响应式布局
- 使用相对单位（rem, em, %）替代固定像素
- 图片使用 max-width: 100% 确保自适应
- 字体大小使用 clamp() 函数实现响应式

## 12. 结论

移动端用户中心的开发将为用户提供更好的移动体验，符合现代移动应用的设计标准。通过合理复用现有组件（Navigation、Button、FormInput、Modal、CardTags 等），增强 CardTags 组件支持交互模式以替代 RecordTypeTabs，新建 MobileUserProfileHeader、MobileUserCenterLayout 两个核心组件，避免组件过度开发，可以创建一个功能完整、性能良好、用户体验优秀的移动端用户中心。

本技术文档提供了详细的开发规划和实现方案，为开发团队提供了清晰的指导。在开发过程中，应严格按照文档要求进行实现，并根据实际情况进行适当调整。
