# 移动端六爻排盘页面改造步骤说明书

## 一、项目概述

### 1.1 项目背景
本项目为圆运阁古易文化网站的六爻排盘功能移动端改造，旨在优化移动端用户体验，提供更加符合移动设备操作习惯的界面布局。

### 1.2 改造范围
- 六爻排盘页面（/divination/liuyao）的移动端样式和布局
- 涉及组件：LiuYaoQiGua、NavigationSidebar、DivinationInfo 等

### 1.3 改造目标
- 优化移动端布局结构，提升用户体验
- 添加顶部导航栏，提供清晰的页面标识和导航功能
- 集成求占者信息表单，完善功能完整性
- 改进起卦方式导航，采用横排布局适应移动端屏幕
- 保持桌面端功能不变，确保兼容性

## 二、改造需求分析

### 2.1 布局结构需求

#### 2.1.1 整体布局
```
┌─────────────────────────────────┐
│     顶部导航栏区域              │
├─────────────────────────────────┤
│     求占者信息区域              │
├─────────────────────────────────┤
│     起卦内容区域                │
│  ┌───────────────────────────┐  │
│  │  横排起卦方式导航         │  │
│  ├───────────────────────────┤  │
│  │  起卦方法内容             │  │
│  └───────────────────────────┘  │
├─────────────────────────────────┤
│     排盘按钮区域                │
└─────────────────────────────────┘
```

#### 2.1.2 顶部导航栏
- 蓝色背景 (#1890FF)
- 包含返回按钮和"六爻排盘"标题
- 三等分布局：返回按钮、标题、占位符

#### 2.1.3 求占者信息区域
- 白色背景，三行布局
- 第一行：姓、名、性别选择器、生年输入框
- 第二行：占类下拉选择、自建子类输入框、占题输入框
- 第三行：时间戳显示组件、属地输入框

#### 2.1.4 起卦内容区域
- 横排起卦方式导航：白色背景，支持横向滚动
- 起卦方法内容：爻位显示和操作按钮

#### 2.1.5 排盘按钮区域
- 居中显示，根据起卦进度启用或禁用
- 蓝色背景，大尺寸按钮

### 2.2 功能需求

#### 2.2.1 导航功能
- 返回按钮：点击返回上一页
- 页面标题：显示"六爻排盘"

#### 2.2.2 表单功能
- 姓、名输入：文本输入
- 性别选择：单选按钮（男/女）
- 生年输入：数字输入，4位限制
- 占类选择：下拉选择（事业、感情、财运、健康等）
- 自建子类：文本输入（可选）
- 占题输入：文本输入，支持较长内容
- 时间戳设置：点击打开时间设置弹窗
- 属地输入：文本输入

#### 2.2.3 起卦功能
- 逐爻起卦：点击投掷，逐个生成爻位
- 一键起卦：一次性生成所有爻位
- 报数起卦：输入数字生成爻位
- 指定起卦：手动指定爻位

#### 2.2.4 排盘功能
- 开始排盘：完成六次投掷后启用
- 结果展示：在新标签页打开排盘结果

### 2.3 样式需求

#### 2.3.1 颜色规范
- 主色调：#1890FF（蓝色）
- 背景色：#FFFFFF（白色）
- 辅助色：#666、#E5E7EB（灰色）
- 强调色：#C00000（红色，阳爻）
- 深蓝色：#002060（阴爻）

#### 2.3.2 字体规范
- 标题：18px，字重500
- 导航项：14px，字重400
- 表单文字：14px，字重400
- 按钮文字：14px，字重500

#### 2.3.3 间距规范
- 页面级间距：16px
- 组件级间距：12px
- 元素级间距：8px
- 内边距：12px-16px

#### 2.3.4 响应式规范
- 小屏幕（<375px）：紧凑布局
- 中等屏幕（375px-768px）：标准移动端布局
- 大屏幕（>768px）：桌面端布局

## 三、技术实现方案

### 3.1 组件架构

#### 3.1.1 主要组件
- **LiuYaoQiGua**：主容器组件，协调各子组件
- **NavigationSidebar**：起卦方式导航组件
- **MethodContent**：起卦方法内容容器
- **DivinationInfo**：求占者信息表单组件
- **Button**：通用按钮组件

#### 3.1.2 组件关系
```
LiuYaoQiGua
├── TopNavigation（新增）
├── DivinationInfo（集成）
├── NavigationSidebar（改造）
│   └── MethodItem
├── MethodContent
│   ├── StepByStepMethod
│   ├── OneClickMethod
│   ├── NumberMethod
│   └── SpecifiedMethod
└── DivinationButtonContainer
```

### 3.2 状态管理

#### 3.2.1 全局状态（AppContext）
- formData：表单数据
- timestamp：时间戳
- setFormData：设置表单数据
- setTimestamp：设置时间戳

#### 3.2.2 组件状态（LiuYaoQiGua）
- selectedMethod：当前选中的起卦方式
- yaoValues：六爻值数组
- yaoOddCounts：六爻奇数计数数组
- currentYaoIndex：当前爻位索引
- isResetEnabled：重置按钮启用状态
- isDivinationButtonEnabled：排盘按钮启用状态
- isThrowing：是否正在投掷

### 3.3 样式方案

#### 3.3.1 CSS Modules
- 使用 CSS Modules 实现样式隔离
- 移动端样式文件：*.mobile.module.css
- 桌面端样式文件：*.desktop.module.css

#### 3.3.2 响应式设计
- 使用媒体查询实现响应式布局
- 动态检测屏幕尺寸，切换样式
- 支持横向滚动（导航栏）

const debounce = (func, wait) => {
  let timeout;
  return function executedFunction(...args) {
    const later = () => {
      clearTimeout(timeout);
      func(...args);
    };
    clearTimeout(timeout);
    timeout = setTimeout(later, wait);
  };
};
